# Opener

An agent that controls and perform tasks on your PC with a voice command.

# In Action
[🎥 Watch Demo Video](./media/opener_presentation.mp4)

## Lets talk in detail
We always had a dream to live like Tony Stark (Ironman). Talking to systems and automating tasks. As a child I always look up to that character and always wanted to have such technologies with me.

Finally, It is now possible by the grace of AI.

So, I built this using python - more specifically, Used MCP server to connect all the tools that perform different operations on my system. Then, I built a pipeline i.e STT -> Agent -> MCP -> Actions.

it's that simple!

By the help of some libraries such as subprocess, os, pyautogui and pygetwindow - It has become possible to access apps and perform actions.
